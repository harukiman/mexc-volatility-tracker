デイトレード向け 推奨パターン

表示データの意味

  • 年率ボラ: 直近 20 本の log return std × √(periods/year) × 100
  • FR: funding rate。 正 = long が short に支払う。 ±0.05% 超は極端
  • OI: open interest（USD）。 OI 増加 + 価格上昇 = 強 trend / OI 減少 + 上昇 = short squeeze 疑い
  • 出来高: 24h 約定額。 $50M 未満は spread/slippage でエッジ消失

パターン 1 — ブレイクアウトモメンタム（順張り）

5m ボラ Top + 24h ゲイナー Top + 出来高 >$100M の重複
① 5m ボラを確認 → ② 急騰急落で上昇率 Top と照合 → ③ 両方に入る銘柄 = 「動いている」
④ FR 正 + OI 増加 = 順張り (trailing stop で伸ばす)
⑤ FR 極端正 (>0.1%) = 過熱、 利確優先

パターン 2 — ミーンリバージョン（逆張り）

5m ボラ Top + 24h ルーザー Top + FR 極端負 (<-0.05%)
① -10% 以上の急落銘柄 + 5m ボラ上位 = panic selling
② FR 深く負 = short crowded → squeeze の R:R 良好
③ 損切り = 直近 swing low の下 / 利確 = VWAP or 5m EMA20

パターン 3 — BTC 連動回避 + alt 個別 setup

BTC 5m/15m が ±0.5% 以内（小動き）+ alt の独立した強さ
① BTC/ETH カードで 5m/15m が ±0.5% 内 = macro neutral
② alt 個別のボラ Top が BTC 連動でなく独自材料 = pure alpha
③ BTC が ±2% 以上動いてる時は alt 個別 setup を無視（連れ高安で flat 化）

パターン 4 — 平均ボラとの比較で「動いてる時間帯」検出

全銘柄平均ボラが急上昇 = 市場全体が動く時間帯
① 3 時間軸の平均ボラを記憶 / 定点観測
② 平均ボラ ×1.5 以上 = 大型イベント or 米国指標時間 = size 縮小
③ 平均ボラ ×0.5 以下 = レンジ / mean-revert 戦略の温床

パターン 5 — マルチ時間軸合致を使った持続性確認

5m + 15m + 1h 全 Top 20 入り = 持続性最高 trend
① 「マルチ時間軸合致」 タブで共通銘柄を確認
② 単一時間軸のみは「短期スパイク」、 早期 fade のリスク
③ 3 時間軸合致 = 数時間続く trend、 順張り保有時間長め可

パターン 6 — シグナルタブの自動推奨を使う

⚡ シグナル タブで「LONG/SHORT 候補 + 期待値」 を直接取得
① タブ「⚡ シグナル」を開くと、 LONG/SHORT スコア 30 以上の銘柄が一覧
② スコア 60+ = 強信号 (複数要因が揃う) / 40-60 = 中信号 / 30-40 = 弱信号
③ 期待値は「中央」予測 (1 時間後の % 変動)。 ATR(1h) × スコア確信度で算出
④ 根拠タグで判断: uptrend / accel / multi-tf / short-crowded 等が良 / illiq / overext は警戒
⑤ 損切りは必ず ATR(1h) × 0.5 = 期待値の半分を逆方向に置く (R:R = 2:1 が最低限)

シグナル根拠タグの意味

  • uptrend / downtrend: 24h ±2〜±8% の素直なトレンド
  • weak-up / weak-down: ±0〜±2% の弱いトレンド
  • overext: +15% 以上で過熱、 long 不利
  • oversold: -15% 以下で売られすぎ、 short 不利
  • short-crowded: FR < -0.02% = ショート過多 = squeeze 候補
  • long-crowded: FR > +0.05% = ロング過多 = fade 候補
  • extreme-fr: FR > +0.1% で long コスト極端
  • fade-pump: 急騰 + 過熱 FR = 逆張り short 好機
  • accel: 5m vol > 15m vol > 1h vol = 短期加速度プラス
  • multi-tf: 3 時間軸合致銘柄 (持続性 trend)
  • liq+ / illiq: 出来高 $100M 以上 / $20M 未満

避けるべきパターン

  • 出来高 $20M 以下: spread/slippage でエッジ消失
  • OI 急減 + 価格急上昇: short covering、 持続性低
  • BTC 急変動中の alt setup: 個別 signal が連動でかき消される
  • FR 極端正 + long entry: cost + 過熱で逆張りに食われやすい
  • 1h ボラ Top のみで判断: 過去の動き、 今 trend ではない可能性
