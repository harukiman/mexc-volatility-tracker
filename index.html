表示データの意味

  • 年率ボラ: 直近 20 本の log return 標準偏差 × √(periods/year) × 100。 大きいほど短期変動が激しい
  • FR: funding rate（永久先物の保有コスト）。 正 = long が short に支払う / 負 = short が long に支払う。 ±0.05% 超は極端
  • OI: open interest（建玉総額 USD）。 OI が増えながら価格上昇 = 強い trend / OI 減少しながら上昇 = short squeeze 疑い
  • 出来高: 過去 24h 約定額（USD）。 $50M 未満は spread/slippage で本来エッジを食う

推奨パターン 1 — ブレイクアウトモメンタム（順張り）

条件: 5m ボラ Top + 24h ゲイナー Top の重複 + 出来高 >$100M
① 5m ボラランキングを確認 → ② 急騰急落タブで上昇率 Top と照合 → ③ 両方に入っている銘柄 = 「動いている」
④ FR が正で OI 増加 = 順張り（小さく入って trailing stop で伸ばす）
⑤ FR が極端正（>0.1%）= 過熱、 利確優先 ＋ 大きく取らない

推奨パターン 2 — ミーンリバージョン（逆張り）

条件: 5m ボラ Top + 24h ルーザー Top + FR 極端負（<-0.05%）
① 急騰急落タブで -10% 以上の急落銘柄を探す → ② 5m ボラも上位 = panic selling
③ FR が深く負 = short crowded → squeeze の risk-reward が良い
④ 損切りは直近 swing low の下 / 利確は VWAP or 5m EMA20

推奨パターン 3 — BTC 連動回避 + alt 個別 setup

条件: BTC 5m/15m が ±0.5% 以内（小動き） + alt の独立した強さ
① BTC/ETH カードの 5m / 15m が ±0.5% 内なら macro fundamental neutral と判断
② alt 個別の ボラ Top が BTC 連動でなく独自材料で動いている可能性 = pure alpha
③ BTC が ±2% 以上動いている時は alt 個別 setup を無視（連れ安連れ高で flat になる）

推奨パターン 4 — 平均ボラとの比較で「動いてる時間帯」検出

条件: 全銘柄平均ボラが急上昇 = 市場全体が動く時間帯
① 3 時間軸の平均ボラを記憶 / 定点観測（数時間おきに数回測る）
② 平均ボラが通常の 1.5 倍以上 = 大型イベント or 米国指標発表時間 = position size 縮小
③ 平均ボラが通常の 0.5 倍以下 = レンジ / mean-revert 戦略の温床

推奨パターン 5 — Funding rate アービ（基本）

条件: FR ±0.1% 超え銘柄 + 出来高 >$50M
① BTC/ETH カードの FR を必ず確認、 funding 次回時刻まで何時間あるか把握（8h cycle）
② 極端 FR は逆方向ポジション保有で 8h ごとに収益化、 但し基礎 price risk あり → 必ず spot or 別venue で hedge
③ FR 単独で取りに行くのは「funding rate carry」戦略、 day trade としては副次的

避けるべきパターン

  • 出来高 $20M 以下の銘柄: bid-ask spread が広く、 sl/tp で本来エッジ消失
  • OI 急減 + 価格急上昇: short covering 疑い、 持続性低い
  • BTC が急変動中の alt setup: 個別シグナルが BTC 連動でかき消される
  • FR が極端正で long entry: position コスト + 過熱で逆張りに食われやすい
  • 1h ボラ Top のみで判断: 過去の動きで、 今動いてるとは限らない → 5m も確認

運用 tips

  • 更新頻度: 1-5 分おきに「データ取得」 ボタンを押すと最新値で再計算
  • セッション選び: 日本時間 16:00 (欧州 OP) / 22:00 (米国 OP) / 翌 04:00 (CME close) で平均ボラ確認
  • BTC dominance 利用: BTC が小動き = alt 個別シグナルが効きやすい / BTC 急変動 = 連動 trade のみ
  • マルチ時間軸の合致: 5m と 15m の両方で ボラ Top にいる銘柄は「持続性が高い」 signal
  • 記録: 上位銘柄のスクショを取って、 1h 後の動きを後検証 → 自分の判断 hit rate を測る
